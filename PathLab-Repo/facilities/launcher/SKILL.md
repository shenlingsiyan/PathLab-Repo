# 指向跳板 · 制作要点

## 设计决策

- **弹射是坐标运算**：`Target = Position + 方向 × 距离`，中途格子一律不检查；
  检查只发生在最终落点（越界 / 不可通行）。中途可飞行越过墙是有意行为；
- **强制连锁 + 独立访问集合**：落点是启用跳板就继续弹，链条只能用
  `HashSet<int> visitedLauncherIds` 判循环——用「次数上限」替代会在长合法链上假失败；
- **失败语义整条化**：链条任何一环失败，整条特殊移动不可用（候选直接不发布），
  绝不返回半截链条；
- **触发面并列**：跳板格本身与四邻格都可主动触发（规格歧义处的裁决：不要求
  先普通移动踩上跳板），已写入 LAUNCHERS.md 第 3 节并自检验证；
- **几何距离与成本分离**：设施代价字段默认 0，飞多远不等于花多少——各算法
  自行计价（01 按 0 + 落点地形费，00 算 1 步）。

## 事件回放

`SpecialTransition` 携带 `TriggeredLauncherIds`（触发顺序）与 `LandingPositions`
（每次落点）；`LauncherPathPlan.Build` 从坐标路径里挑出非 4 邻接步并匹配
`TransitionType.Launcher`，匹配不上则整条路径无效（审计拒绝），传送门步静默跳过。

## 兼容性

- 跳板在探针链**最外层**（`_launchers.ApplyTo(...)`）且无缓存，每次查询按当前地图重算；
- 与嘲讽点：跳板**最终落点**置位掩码，连锁中间落点不是路径节点不置位；
- 禁用跳板按普通格处理，不发布候选。

连锁落点障碍 / 循环 / 禁用 / 边界 / 寻路端到端 / 事件回放审计，共 12 组 65 条断言
