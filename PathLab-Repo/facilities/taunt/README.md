# 单次嘲讽点（Single-use Taunt Point）

红色小正方形的选择性放置设施。**不阻挡、不改地形代价、不改普通邻接、不控制移动**——
它是一条寻路约束：每次寻路，指针必须经过所有「能纳入合法起点→终点路线」的嘲讽点
（有效集合 `T'`），每点一次，全部访问完才能在终点结束。
「单次」是**每次寻路**语义，不是全局消耗（无冷却/耐久/次数扣减）。
完整规则见 [../PathLab/TAUNTS.md](../PathLab/TAUNTS.md)。

- 数据：`TauntPoint { Id, Position, Enabled }`；仅限地图内、非起终点、空格；
- 有效集合：`T' = { t ∈ T | 存在合法 S→G 路径经过 t }`——可达**且**访问后仍能到终点，
  缺一不可；由 `TauntPlan.Build` 在 `(位置, 进入格)` 状态图上做正反双向可达判定；
- 搜索状态：`(Cell, From, VisitedMask)`；终点判定 `位置 == 终点 && 掩码 == 全有效掩码`；
- 无解语义：有效点无法被**同一条**合法路径共同访问 → 返回无合法路径 +
  调试信息（`MissedTauntCells`），绝不静默丢弃有效点；
- 动态性：计划**每次寻路前重建**（`PlanAll`），无缓存。
