# 混乱传送门（Portal）

门与门是**全对多双向连接、没有固定配对**：从任意门格发起移动，可以落到任意
其他门格，由算法自己按目标挑选出口。门格永远不可通行（设为墙并记住原价）。
完整规则见 [../PathLab/PORTALS.md](../PathLab/PORTALS.md)。

- 数据：任意多个门，格子即身份；门格不可停留；
- 连接：`SpecialTransitions(门格)` 发布到所有其他门格的候选，带门费字段；
- 界面：`传送门` 模式左键放置、右键移除；
- 计价：`00` 传送算 1 步；`01` 门费 + 落点地形费；`06` 权重 0；`07` 落点按参考点计穿越。
