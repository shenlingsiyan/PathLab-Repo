# 单向通道（One-Way Corridor）

占据一个仍可通行的格子，禁止「从首部侧进入」与「向尾部侧离开」两条边，
且穿越必须直线：尾进首出、侧进对侧出，通道内不拐弯。传送落点保留除尾侧外的
全部出口。完整规则见 [../PathLab/ONEWAY.md](../PathLab/ONEWAY.md)。

- 数据：格子 + 方向（首→尾）；通道格本身可通行；
- 连接：不发布特殊移动，而是在探针层用 `ExitsAfter(进入格, 当前格)` **收紧**普通出口；
- 界面：`单向` 模式 + `箭头` 下拉框放置；
- 关键性质：所有接入探针的算法自动遵守，**算法内部零判断**。
