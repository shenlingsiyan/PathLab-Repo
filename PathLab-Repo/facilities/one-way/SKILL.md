# 单向通道 · 制作要点

## 设计决策

- **收紧出口而非发布连接**：通道改变的是普通移动的方向性，所以挂在
  `ExitsAfter(entry, cell)`（探针缺省实现 = 普通邻接）上。算法只要改用
  `ExitsAfter` 取步行出口，不需要知道通道存在；
- **状态分裂是核心技巧**：「从这里出发能去哪」依赖「从哪个方向进的」，
  所以搜索状态必须从 `Cell` 扩成 `(Cell Here, Cell From)`。路径式模块不用分裂
  （读前驱即可），扩散式模块（BFS/Dijkstra/字典序）必须分裂；
- 特例规则明确列举：传送落点无几何进入（From = 自身），保留除尾侧外全部出口；
  步行进入通道后不再取传送。

## 对算法的契约

带 `Probe` 的模块应统一：取步行出口用 `ExitsAfter(进入格, 当前格)`、状态按
`(格子, 进入格)` 分裂。这两条在 `algorithms/README.md`「接受地图设施连接」一节登记，
新增算法照做即自动兼容通道与未来同类的方向性机制。

## 自检要点

- 尾进首出、侧进对侧出、通道内不拐弯逐条断言；
- 状态分裂后不漏终点判定（每个 goal 判定处都带上 From 分量）；
- 与传送门叠加：落点在通道格上的出口规则。
