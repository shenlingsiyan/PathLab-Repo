# 06_max_perpendicular_route · 得分型模块（最大垂直距离）

## 口径

标记点 `Q`，在**不重复格子的简单路径**中最大化
`Σ 步长 × 该步所在直线到 Q 的垂直距离`——横向移动权重 `|y − qy|`，纵向移动权重
`|x − qx|`，设施跳跃无方向权重 0。

## 制作要点

- **简单路径是防刷分前提**：允许重复格子就能绕圈无限刷分。DFS 枚举时用访问矩阵
  保证不重复；
- **精确与近似分层**：`Exact` = DFS + 安全上界剪枝（跑完才算精确），
  `Beam` = 束搜索（永不证明最优）。预算耗尽返回已有最好合法路线 +
  `未证明最优`，绝不冒充最优——`IsOptimal` 逐结果报告，模块级 `Optimal = false`；
- **独立评分函数必须不同源**：`CalculatePathScore` 只走最终路径重算，
  不碰搜索累加器；`--selftest` 用它比对报告值，不一致即失败；
- **得分模块没有通用对照**：`SearchObjective.Score` 时自检通用循环只打 SKIP，
  正确性全靠模块自己的 oracle——所以独立评分函数不是可选项；
- `TerminationReason` 用固定短语（找到精确最优 / 节点上限 / 时间上限 / 不存在合法路径）。

## 嘲讽点接入

- 种子路径换成带 `Taunt` 的 `00`（保证有合法起点）；
- DFS 与 Beam 的**每一个** goal 判定点都加 `TauntComplete(path)` 过滤
  （本模块有两个 goal 判定点，漏一处就出现「有时违反约束」）；
- 约束只过滤解、不改评分公式。

## 自检要点

- 路径合法性（4 邻接、不进墙、无重复）+ 报告分数 = 独立重算 + 代价一致性 +
  必有终止原因；小图全枚举简单路径当 oracle。
