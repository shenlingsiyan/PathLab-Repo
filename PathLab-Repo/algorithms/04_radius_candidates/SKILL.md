# 04_radius_candidates · 半径候选查询模块

## 口径

- 基准：出怪口到入怪口的最短步数 `L`，基准半径 `floor(L * alpha)`；
- 在可选整数区间 `[minRadius, maxRadius]` 内选定半径；**两端都可缺省**（缺省取基准 R）；
- 两端相同 = 圆周，不同 = 圆环；候选 = 半径上**可通行且从入怪口可达**的格子。

## 契约要点

- 区间不合法（负数或下界 > 上界）→ 返回 `InvalidRadiusRange`，**不交换、不夹取**——
  静默修正输入是查询模块的大忌；
- **「成功但 0 个候选」是合法结果**，调用方不得把空结果当失败；
- 每个候选带自己的信息（坐标、实际可达距离），缺字段就是不完整答案。

## 与路径模块的边界

同 02：只回答一个问题，不产生路径，不进下拉框。返回结构里没有 `Path` 字段
不是遗漏，是分类正确。

## 自检要点

- `alpha` 边界（0 / 1 / 大于 1）、区间缺省、非法区间、圆周 vs 圆环、
  全墙半径（0 候选仍成功）。
