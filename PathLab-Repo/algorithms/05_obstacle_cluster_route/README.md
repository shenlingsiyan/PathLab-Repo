# 05 · 障碍群周边最短路径

特殊敌人的**受约束路线**：路线必须至少经过参考点所在**连通障碍群**四周的一格，
在这个前提下再从出怪口走到入怪口，并让**总进入代价最小**。

与前四个模块的区别：它是一个**带约束的最优路径**模块。不满足约束的路线（哪怕更便宜）
一律不合法；满足约束的路线中，只比总代价。

| 项 | 值 |
|---|---|
| Id | `05-obstacle-cluster-route` |
| 类型 | 路径模块 `IPathfinder` + `IReferencePointModule` + `IViaPointModule` |
| 实现 | `ObstacleClusterPathfinder` |
| 目标 | `Cost`（进入代价之和），`Optimal = true`，`Constrained = true` |
| 依赖 | 核心层纯函数 `ObstacleCluster`；不调用 00/01 |
| 复杂度 | 时间 `O(V log V + E)`（两趟 Dijkstra），空间 `O(V)` |

## 口径

### 1. 障碍群

从参考点出发，沿**4 邻接的墙**（代价 0）做一次 BFS，得到的整块连通墙就是障碍群：

- 参考点本身必须是墙，否则失败（不猜、不替换）；
- 对角相邻的墙不算连通，属于另一个障碍群；
- 障碍群只读地图，不回写任何格子。

### 2. 周边格 `ring`

障碍群每个格子的 4 邻接格中，去掉出界与墙，剩下的就是周边格：

- 一个周边格同时贴着障碍群多个格子时**只记一次**；
- 按行优先（先 `y` 后 `x`）排列，保证同一张图结果可复现；
- 贴着地图边界的障碍群，界外方向直接忽略（例如角落单格墙只有 2 个周边格）；
- 周边格列表输出到 `RingCells`，载体用空心方框画出。

### 3. 约束

路径 `P` 合法，当且仅当：

```text
P 是 4 邻接、可通行（非墙）的 S → E 路线
且 P 至少包含一个 ring 中的格子
```

### 4. 代价

```text
总代价 = Σ 进入的格子代价（起点不计费，终点计费）
```

与 00/01 一致。约束只加“必须经过”，不改变计价方式。

## 流程

1. 校验：空地图、参考点缺失/越界、参考点非墙、S/E 越界或为墙；
2. 取障碍群与周边格；周边格为空 → 失败；
3. 从 `S` 跑一趟加权 Dijkstra（起点代价 0），得 `distF` / `stepsF` / `prevF`；
4. 从 `E` 跑一趟加权 Dijkstra（起点计 `CostAt(E)`），得 `distB` / `stepsB` / `prevB`；
   两趟的松弛完全相同：进入下一格付它的价；平局按 `(cost, steps, y, x)`；
5. 对每个周边格 `t`：

   ```text
   total(t) = distF[t] + distB[t] - CostAt(t)
   steps(t) = stepsF[t] + stepsB[t] - 1
   ```

   衔接格 `t` 在两段里都被计了一次，所以减一次；两段都不可达的 `t` 跳过；
6. 取 `total` 最小者，平局比 `steps` 少者，再平局取行优先；
7. 用 `prevF` 还原 `S..t`、用 `prevB` 续上 `t..E`，衔接格只出现一次；
8. `Cost` = 路径逐格求和（与 01 的“起点不计费”口径一致）。

不需要第三个搜索：两趟距离场已经覆盖“从 S 到任意周边格”和“从 E 到任意周边格”。

## 输入 / 输出

```csharp
var module = new ObstacleClusterPathfinder();
module.ReferencePoint = new Cell(0, 5);   // 必须是墙
SearchResult result = module.Search(map);

result.Found        // 是否有满足约束的路线
result.Cost         // 该路线总进入代价
result.Path         // S → 周边格 → E
result.Note         // 失败原因；成功时为 null

module.UsedReference  // 上次搜索实际使用的参考点（失败时也可能已回填）
module.RingCells      // 上次搜索的周边格（行优先，失败时可能为空）
module.ViaCell        // 上次搜索实际经过的周边格（失败时为 null）
module.FarthestPoint  // 本模块不用，恒为 null
```

`FarthestCell` 一类的旧接口仍被实现，是为了让载体复用「参考点行 / 角标 / 空心方框」的绘制通道。

## 失败状态

| 情况 | `Note` | 其他字段 |
|---|---|---|
| `map` 为 `null` | `地图为空` | `RingCells` 空，`ViaCell` 空 |
| 参考点未设置或越界 | `参考点超出地图边界` | 同上 |
| 参考点不是墙（例如空地） | `参考点不是障碍` | 同上 |
| S 或 E 越界 / 是墙 | `出怪口或入怪口不可通行` | 已记下参考点与周边格 |
| 周边格为空（障碍群四周全是墙/界外） | `障碍群周围没有可通行格子` | `RingCells` 空 |
| 没有任何周边格同时连到 S 与 E（如被封闭房间围住） | `周边格子无法同时连接出怪口与入怪口` | `RingCells` 仍照常给出 |

失败一律**退化**：不会偷偷放宽约束、不会换成无障碍最优路径、不会替换参考点。

## 测试（`--selftest`）

| 用例 | 构造 | 断言 |
|---|---|---|
| A 障碍群收集 | 孤立墙；相连墙；对角墙 | 单格群；连成一群；对角各自成组 |
| B 周边格数量 | 单格墙 / L 形墙 / 角落墙 | 4 个 / 7 个（去重） / 2 个（界外忽略） |
| C 去重 | 一个空地同时贴两块群墙 | 只出现一次，且周边格不会是墙 |
| D 合法路线 | 参考点偏离直连路线 | 路径 4 邻接、不穿墙、含周边格 |
| E 强制绕行 | 9×9，墙在 `(0,5)`，S=(0,0)，E=(8,0) | 代价 16，高于无约束最优 8 |
| F 顺路不加价 | 墙挡在直连桥上 | 代价 10，等于无约束最优 10 |
| G 高价侧避让 | 三面周边格涂 9 | 选空着的一侧 `(5,4)`，代价 12 |
| H 约束不可满足 | 障碍群关在封闭房间里 | 失败并给出“无法同时连接”，周边格仍为 4 |
| I 贴边障碍群 | 角落墙，参考点在角落 | 周边格 2 个，代价 22 与 oracle 一致 |
| J 代价与约束叠加 | 7×7，墙 `(3,3)` + 三个高价格 | 代价 8：绕墙路线的周边格本就顺路，约束不额外加价 |
| K 实例无状态 | 同实例两次、中间加一格墙 | 周边格 4 → 6，与现场重扫一致 |
| oracle | 独立实现：逐周边格 clone 地图，分别以 `t` 为 `Goal` / `Start` 跑 01 | 总代价与经过格逐项一致 |
| 失败分支 | 空图 / 越界 / 空地参考点 / 缺参考点 / 不可通行 S/E | 对应 `Note`，且不退化 |

oracle 的成本口径：`legIn.Cost + legOut.Cost`。01 的起点不计费，所以第二段已经不含衔接格，
两段直接相加即为整条路线的总代价（不要再多减一次 `CostAt(t)`）。

## 约束

- 不修改地图与障碍群定义：只读 `CostAt`，不写回；
- 不放松约束：没有满足条件的路线就失败，绝不返回更便宜的无约束路线；
- 不用“周边格质心 / 最近周边格 / 到周边格的曼哈顿距离”替代真实绕行代价；
- 只在周边格上做比较，不做全图第三趟搜索（两趟距离场足够）；
- 停滞、候选挑选、敌人状态机不在本模块内；
- 平局规则固定为 `(总代价, 步数, y, x)`，同一张图必须复现同一条路线。

## 传送门（特殊连接）

本模块实现 `ITransitionAware`：

```csharp
module.Probe = probe;   // null = 纯 4 邻接
```

- 两趟 Dijkstra（出怪口出发 / 入怪口出发）都接受传送边，边权为 `门费 + 落点地形费`；
- 约束环仍是**普通格**：门格是墙，不会出现在 `ObstacleCluster.Ring` 里；
- 只有门能到达的障碍群因此也能满足约束（自检 `portal 05`：墙把地图切开，接探针后才成功）；
- `Cost` 逐格重算并对每次传送补一次门费，与报告值独立复核；
- `Probe = null` 时行为与本文件前面的描述一致。
