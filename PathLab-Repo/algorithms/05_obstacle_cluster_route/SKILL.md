# 05_obstacle_cluster_route · 障碍群周边约束模块

## 口径

- 参考点**必须是墙**；取其 4 邻接连通的整块障碍群；
- 约束目标 = 障碍群四周一圈的**可通行格**，路线至少经过其中一格；
- 在满足约束的路线中取**总进入代价最低**（两趟 Dijkstra：起→各周边格的前置代价 +
  各周边格→终点的后置代价，枚举周边格取 `min`）。

## 制作要点

- **`Constrained = true` 必须声明**：约束下的代价可以合理地高于无约束最优，
  `--selftest` 据此跳过普通最优对照，改用模块自己的约束 oracle——不声明就会
  被「比无约束最优还贵」误判为错误；
- 失败必须给**原因**：无墙参考点 / 障碍群四周全封死 / 终点不可达，各自固定短语；
- 周边格以 `IViaPointModule.RingCells` 交给载体画空心方框，实际经过格用
  `ViaCell` 画 `F` 角标——约束的可视化与约束本身分离；
- 默认参考点 = 行优先**第一个墙格**（载体按模块类型给默认值，见
  `algorithms/README.md`「需要参考点的路径模块」）。

## 嘲讽点为何不接入

两趟 Dijkstra 的「前置 + 后置」结构无法再叠加必经点集合而不重写路线定义。
载体状态栏提示「不执行嘲讽点约束」，不静默违反。

## 自检要点

- 约束 oracle：独立验证路径确实经过群周边、代价与路径重算一致、
  无约束解会被正确拒绝；
- 参考点是空地 → 失败 + Note（不静默换成邻格）；障碍群贴边、群把地图分成两半等几何边界。
